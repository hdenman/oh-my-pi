# Ctrl+D forwards to delete-forward

By default, `ctrl+d` is bound to `app.exit` in Oh My Pi's keybindings. This is problematic because `ctrl+d` is also the standard `delete-forward` keybinding in many terminals and applications.

To allow `ctrl+d` to function as `delete-forward`, its binding to `app.exit` must be removed.

Two files need to be updated:

- `packages/coding-agent/src/config/keybindings.ts`: Set `defaultKeys: []` for `app.exit`.
- `packages/coding-agent/src/modes/components/custom-editor.ts`: Set `DEFAULT_ACTION_KEYS["app.exit"]` to `[]`.

This unbinds `ctrl+d` from `app.exit`, allowing the terminal's native `delete-forward` to take effect.
