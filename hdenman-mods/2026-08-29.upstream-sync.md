# Syncing with upstream/main (2026-08-29)

When upstream advances and the hdenman modifications need to move forward:

## What we carry

Three categories of changes live on top of upstream/main:

1. **Keybinding fix** — `ctrl+d` unbound from `app.exit` in two files so it falls
   through to delete-forward.
2. **Local-build scaffold** — `scripts/build-local.ts`, `shell.nix`, and a
   `"build:local"` entry in the root `package.json`.
3. **`hdenman-mods/` docs** — this directory.

## Procedure

```sh
git fetch upstream
git checkout -b hdenman-rebase upstream/main
```

Then apply each category in order:

1. **Keybinding** — cherry-pick the commit that clears `defaultKeys` on `app.exit`:
   ```sh
   git log --oneline ctrl-d-delete-forward ^upstream/main -- \
     packages/coding-agent/src/config/keybindings.ts
   git cherry-pick <sha>
   ```
   If it conflicts, manually set `defaultKeys: []` on `app.exit` in both
   `packages/coding-agent/src/config/keybindings.ts` and
   `packages/coding-agent/src/modes/components/custom-editor.ts`.

2. **Local-build** — cherry-pick cleanly applicable commits from the old branch:
   ```sh
   git cherry-pick <local-build-sha>       # adds scripts/build-local.ts + package.json line
   git cherry-pick <better-build-sha>      # OR: git checkout <sha> -- scripts/build-local.ts
   git cherry-pick <build-bindings-sha>    # delegation fix
   git cherry-pick <shell.nix-sha-range>   # all shell.nix iterations
   ```
   Check `scripts/build-local.ts` for calls to scripts that upstream may have dropped
   (run `bun run --dry <script>` or check `package.json` in upstream). Remove any that
   no longer exist.

3. **Docs** — copy `hdenman-mods/` from the old branch:
   ```sh
   git checkout ctrl-d-delete-forward -- hdenman-mods/
   ```

## Finalize

Run `bun run build:local` to confirm the build succeeds on the new upstream base.
Then force-update the canonical branch:

```sh
git branch -f ctrl-d-delete-forward hdenman-rebase
git push origin ctrl-d-delete-forward --force-with-lease
git branch -d hdenman-rebase
```
